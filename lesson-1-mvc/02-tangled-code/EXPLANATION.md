# Van tangled code naar MVC

De starter laat één functie data lezen en muteren, HTML maken, meldingen tonen en listeners koppelen. In de solution:

- bewaart het Model de boeken en beslist het of Borrow is toegestaan;
- rendert de View en rapporteert die een klik;
- converteert en coördineert de Controller;
- importeert `main.js` alleen de Controller en start het daarmee de app.

De functionaliteit blijft klein; de reden tot wijzigen per onderdeel wordt duidelijker.
