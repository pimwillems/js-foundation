# 04 — Traceer een klik

Reconstructeer twee routes met `starter/trace.md`:

```text
click → View → Controller → Model → Controller → View
```

Eén route slaagt, één route faalt. Syntax is bewust klein gehouden.

Voorspel eerst de zichtbare uitkomst. Traceer daarna waarden en aanroepen, leg per stap de verantwoordelijkheid uit, verander de beginsituatie en verifieer met de solution.
