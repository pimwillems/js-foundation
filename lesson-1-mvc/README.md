# Les 1 — MVC vóór syntax

In deze les onderzoek je eerst **waar verantwoordelijkheden horen**. Je hoeft nog niet alle JavaScript-symbolen te kunnen benoemen. Noteer juist wat je niet kunt verklaren.

Werk in volgorde: gebruik de app, vergelijk tangled code met MVC, classificeer verantwoordelijkheden, traceer een klik en doe daarna de diagnostische eerste poging. Les 2 beantwoordt de syntaxvragen die hier ontstaan.
