# 05 — Eerste poging: Borrow

Dit is een **diagnostische poging**, geen toets of bewijs dat je zelfstandig complete JavaScript moet kunnen schrijven. Probeer Borrow te verbinden in de starter, maar stop niet bij “werkt niet”.

## Voor je wijzigt

Voorspel waar de klik binnenkomt en welke route nodig is. Traceer de bestaande render. Leg met eigen woorden uit wat elk bestand bezit.

## Tijdens je poging

Gebruik `starter/learning-log.md` en noteer:

- wat je begrijpt;
- wat je deels kunt uitleggen;
- wat je nog niet kunt uitleggen;
- welke vragen les 2 moet beantwoorden.

De TODO's raken arrays/objecten, properties, functies/parameters, conditions, DOM, events, opnieuw renderen en imports/exports. Verifieer iedere kleine wijziging. Bekijk pas daarna de referentieoplossing.
