# Functies

Vergelijk een function declaration met een arrow function. Functies kunnen parameters ontvangen en een waarde teruggeven, maar dat hoeft niet altijd. Arrow functions zijn niet automatisch beter.

## Voorspel → traceer → leg uit → verander → verifieer

Voorspel beide returnwaarden. Traceer parameter `book` en argument `books[0]`. Leg uit waarom `logBook` geen nuttige return nodig heeft. Wijzig de functie zodat die de auteur retourneert. Verifieer met Node.

De starter bevat gerichte TODO's. De solution laat de belangrijke verschillen in comments zien en bevat geen verborgen magie.
