# 06 — DOM-selectie en rendering

Leer `querySelector`, template literals en renderen. De View mag kleine presentatiekeuzes maken, zoals statuslabels en CSS-classes; domeinregels horen niet in de View.

1. **Voorspel:** teken de HTML na de eerste render.
2. **Traceer:** volg `books → renderBooks → innerHTML`.
3. **Leg uit:** benoem het DOM-side effect.
4. **Verander:** voeg de auteur toe in de starter.
5. **Verifieer:** open via de lokale server en inspecteer Elements.

De solution rendert semantische lijstitems en escaleert geen state-wijzigingen naar de View.
