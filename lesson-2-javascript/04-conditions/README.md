# Conditions en early returns

Gebruik booleans, `if`, `else`, `===`, `!==`, `!` en early returns om domeinregels leesbaar te maken.

## Voorspel → traceer → leg uit → verander → verifieer

Voorspel de resultaten. Traceer bij welk returnpunt elke aanroep stopt. Leg uit waarom strict equality past en vergelijk een guard met een expliciete `if/else`. Voeg een guard toe voor een ongeldig ID. Verifieer.

De starter bevat gerichte TODO's. De solution laat de belangrijke verschillen in comments zien en bevat geen verborgen magie.
