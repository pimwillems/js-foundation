# Arrays en objecten

Lees een collectie boekobjecten, gebruik property access en zie het verschil tussen een array en het object erin.

## Voorspel → traceer → leg uit → verander → verifieer

Voorspel de uitvoer. Traceer `books[1].available`. Leg uit welke waarde de array en welke het object is. Voeg een boek toe. Verifieer met Node.

De starter bevat gerichte TODO's. De solution laat de belangrijke verschillen in comments zien en bevat geen verborgen magie.
