# Variabelen en state

Onderzoek `const`, `let`, primitives en objectmutatie. De titel is een string, de teller een number en beschikbaarheid een boolean: dat zijn primitive values. Deze cursus vermijdt `var` omdat function scope en hoisting extra verrassingen geven die hier niet nodig zijn.

## Voorspel → traceer → leg uit → verander → verifieer

Voorspel welke logs veranderen. Traceer de waarde én het type. Leg uit waarom een object achter `const` wel kan muteren. Wijzig de titel en een teller. Verifieer met `node exercise.js`.

De starter bevat gerichte TODO's. De solution laat de belangrijke verschillen in comments zien en bevat geen verborgen magie.
