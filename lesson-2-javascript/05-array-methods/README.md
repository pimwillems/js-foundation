# find, forEach en map

`find` zoekt één element en kan `undefined` geven. `forEach` voert iets uit per element en levert geen nieuwe bruikbare collectie op. `map` bouwt juist een nieuwe array.

## Voorspel → traceer → leg uit → verander → verifieer

Voorspel waarden en returntypes. Traceer iedere callback. Leg het verschil tussen `forEach` en `map` uit. Maak een titellijst. Verifieer.

De starter bevat gerichte TODO's. De solution laat de belangrijke verschillen in comments zien en bevat geen verborgen magie.
