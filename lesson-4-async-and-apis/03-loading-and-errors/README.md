# 03 — Loading, error en empty state

Een async scherm heeft minstens vier toestanden: loading, succes met data, succes zonder data en error.

1. Voorspel de statusvolgorde voor de geldige en kapotte URL.
2. Traceer `try/catch/finally`.
3. Leg uit waarom loading altijd moet eindigen.
4. Verbind de knoppen in de starter.
5. Verifieer beide paden; fouten zijn lokaal en deterministisch.

De solution toont gebruikersfeedback en slikt errors niet stil in.
