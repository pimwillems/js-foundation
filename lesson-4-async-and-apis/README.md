# Les 4 — Async code en API's (optioneel)

Deze les is een optionele vierde sessie. Alle data komt uit `/shared/books.json`; er is geen externe API of account nodig.

De kernvraag blijft architectuur: het Model wisselt van hard-coded data naar `fetch`, maar de View hoeft niet te weten waar boeken vandaan komen en de Controller blijft laden en renderen coördineren.
