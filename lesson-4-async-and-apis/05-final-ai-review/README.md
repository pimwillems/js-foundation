# 05 — Finale AI-review

## Fictief verzoek

> Laad boeken vanuit een API en laat fouten niet in de weg zitten.

De starter is **bewust onveilig en defect**. Leg ieder probleem uit vóór je het corrigeert: ontbrekende `response.ok`-check, loading nooit gewist, stil ingeslikte fout, meerdere requests, DOM-toegang in het API-Model en onveilige rendering van ontvangen tekst.

1. Voorspel symptomen en veiligheidsrisico.
2. Traceer request lifecycle en state.
3. Classificeer in `starter/review.md`.
4. Corrigeer contract en rendering.
5. Verifieer met lokale data en vergelijk met solution.
