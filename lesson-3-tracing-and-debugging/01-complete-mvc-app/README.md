# 01 — Complete MVC-referentie

Dit is de schone referentie met Borrow, Return, Search en een duidelijke empty state. De starter is een werkende kopie om annotaties en experimenten in te maken; de solution blijft je vergelijkingspunt.

1. Voorspel de dependency direction vanaf `main.js`.
2. Traceer één succesvolle en één geweigerde actie.
3. Leg uit waarom result objects nuttiger zijn dan alleen `true`/`false`.
4. Verander tijdelijk een begintoestand in starter.
5. Verifieer en herstel je experiment.

Listeners worden één keer gekoppeld; rendering vervangt alleen HTML. Er zijn geen circulaire imports.
