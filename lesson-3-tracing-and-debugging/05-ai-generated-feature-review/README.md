# 05 — Review een AI-gegenereerde Return-feature

## Fictief verzoek

> Voeg snel een Return-knop toe. Houd de rest werkend.

De starter bevat `generated-change.js`: een plausibele wijziging die visueel lijkt te werken, maar laaggrenzen en randgevallen schendt. De solution bevat een complete gecorrigeerde app.

1. Voorspel gedrag voor bestaand, beschikbaar en onbekend boek.
2. Traceer de mutatie en render.
3. Vul `starter/review.md` in vóór je code wijzigt.
4. Maak een minimale correctie met een Model-result object.
5. Verifieer en vergelijk met solution.
