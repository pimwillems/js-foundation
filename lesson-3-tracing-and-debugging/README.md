# Les 3 — Traceren en debuggen

Nu verbind je losse syntaxconcepten tot één mentaal model. Je werkt van waarneembaar gedrag terug naar event, invoer, Controller, Model-state en render.

Gebruik bij elk vermoeden de cyclus: voorspellen, een smal spoor verzamelen, verklaren, minimaal wijzigen en opnieuw verifiëren.
