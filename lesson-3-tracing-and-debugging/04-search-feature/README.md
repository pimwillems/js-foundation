# 04 — Search toevoegen

Voeg zoeken toe zonder de originele boekencollectie te vervangen.

1. Voorspel het resultaat van zoeken, wissen en een zoekterm zonder matches.
2. Traceer input string → View callback → Controller → Model query → afgeleide collectie → render.
3. Leg uit: de zoekterm is Model-state; de View rapporteert input; de Controller coördineert.
4. Maak de TODO's af.
5. Verifieer ook dat alle boeken terugkomen na het wissen.

Filtering leidt een zichtbare collectie af en muteert `books` niet.
