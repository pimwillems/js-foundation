# 03 — Acht onafhankelijke bugs

De bestanden in `starter/scenarios` zijn **bewust defecte, losse scenario's**. Repareer ze niet allemaal tegelijk.

1. Voorspel symptoom en eerste bewijs.
2. Traceer alleen relevante waarden/aanroepen.
3. Leg oorzaak uit zonder meteen een fix te noemen.
4. Pas de kleinste gerichte verandering toe.
5. Verifieer met een concrete test en vergelijk met `solution/scenarios`.

Gebruik `HINTS.md` pas nadat je zelf één observatie hebt verzameld.
