# Checklist voor het lezen van JavaScript

Schrijf je voorspelling op voordat je de code uitvoert. Verifieer daarna in de browser, console, debugger of tests.

1. Waar begint de uitvoering?
2. Welke invoer komt deze functie binnen?
3. Welk type heeft die invoer?
4. Wat geeft de functie terug?
5. Welke state leest de functie?
6. Welke state verandert de functie?
7. Welke laag is eigenaar van die verandering?
8. Welk side effect vindt plaats, bijvoorbeeld DOM-wijziging of netwerkverzoek?
9. Wat gebeurt er als data ontbreekt of ongeldig is?
10. Waardoor rendert de View opnieuw?
11. Kan een event listener meer dan één keer worden gekoppeld?
12. Hoe kan ik mijn voorspelling controleren?
